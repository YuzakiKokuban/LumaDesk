# 机耀处 · LumaDesk 0.2.0-beta.4

- 应用设置后保留页面和控件，后台更新读回结果；系统页仅更新相关设置组，滚动位置保留，失败不清空旧数据。
- 亮度与 OEM 热键通知支持初次失败重试、断线重连；睡眠恢复请求重新连接，系统页提供手动重连。
- MUX 待重启状态保存到磁盘，退出应用再打开仍能提示。固件已保存与实际显示路由生效分别说明。
- 配置保存加入进程间锁、唯一临时文件和失败回退，避免桌面与 CLI 同时修改丢失设置。
- 设置反馈使用中文，概览显示数据更新时间；日志保留历史，支持诊断导出和配置备份。
- 新增默认关闭的 AC/DC 自动性能档位，托盘快捷切换性能档位和强冷。
- OSD 消失不再触发内存回收；主窗口收起后延迟清理，重新打开取消等待，限制清理频率。
- CI 拆分检查、审计与打包；发布标签自动同步版本，生成提交更新日志，并在全部检查通过后发布校验过的产物。

本机 Release 模拟界面检查及 200% 缩放窄窗口复核通过，原生 WMI 订阅与重连通过被动验证。仍需实机确认实际 MUX 重启、充电截止、背光效果、完整 Fn 组合、睡眠恢复与重新登录自启。

提供 Windows x64 安装器、便携 ZIP 和 SHA256；保留共享 .NET 10 / Windows App SDK Runtime 及原厂 UWACPIDriver 依赖。
