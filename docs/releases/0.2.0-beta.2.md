# 机耀处 · LumaDesk 0.2.0-beta.2

本次预发布加入托盘常驻与实际 OSD，修复 Win 键锁和安装依赖引导。当前主要适配机械革命耀世 15 Air。

- 关闭窗口或最小化后收起到任务栏通知区域；双击图标重新打开，右键菜单可退出。主界面未打开时暂停硬件监控与扫描，热键和系统通知通过事件接收。
- 接管原厂控制中心后，Fn+F1 可呼出机耀处；Fn+F3 切换 Win 键锁，系统设置中的开关同步状态。锁定时拦截左右 Win 键，其他按键继续使用。
- 去除 OSD 圆角周围的系统浅色边框；新配置默认不透明度降为 60%，可自定义 20%–100%，保留位置、主题和显示时长设置。
- 按 Fn+Esc、Fn+F2 至 Fn+F12 的实际功能显示相应提示，新增 Caps Lock、Num Lock、Scroll Lock 和电源连接变化提示。部分提示依赖本机固件事件或 Windows 状态通知，其他机型的事件映射仍需验证。
- 安装程序固定要求管理员权限；缺少 x64 .NET 10 Runtime 或 Windows App SDK Runtime 时打开对应官方下载页，安装依赖后可在原向导中重试。
- 升级后自动将既有的本程序登录任务改为后台启动，并保留原启用状态和任务设置。

下载提供 Windows x64 安装 EXE 与便携 ZIP，均附 SHA256 校验文件。程序共用系统运行时，仍需保留原厂 UWACPIDriver，运行组件要求见 [RUNTIMES.md](https://github.com/YuzakiKokuban/LumaDesk/blob/v0.2.0-beta.2/docs/RUNTIMES.md)。

Fn+F1 与 Fn+F3 的固件事件已在本机采集确认；Win 键锁已通过实际 Windows 键盘钩子注入检查。完整 Fn 组合在其他机型上的实机效果尚未验证。验证范围与记录见 [VALIDATION.md](https://github.com/YuzakiKokuban/LumaDesk/blob/v0.2.0-beta.2/docs/VALIDATION.md)，发布工作流重复执行构建、协议测试、包内容检查、依赖判定及安装卸载检查。
