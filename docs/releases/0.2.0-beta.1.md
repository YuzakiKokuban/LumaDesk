# 机耀处 · LumaDesk 0.2.0-beta.1

首个预发布版本，当前适配机械革命耀世 15 Air。

下载：安装 EXE **9.23 MiB**，便携 ZIP **12.67 MiB**。解压后的程序 **43.67 MiB**；本机平均私有内存从约 179 MiB 降至 161 MiB。

- 同时提供 Windows x64 安装 EXE 与便携 ZIP，均附 SHA256 校验文件。
- 共用系统 .NET 和 WinUI 运行时，减小下载和安装目录。安装程序检查依赖、创建快捷方式，卸载时恢复官方控制中心并保留个人设置。
- 页面切换采用 160 ms 淡入淡出，遵循 Windows 动画设置；侧边栏切换不累积返回历史。
- 缓存机型、BIOS、电池健康和低频时钟查询，减少后台 WMI 调用；操作后的状态刷新仍立即执行。
- 保留原 Logo 和白色圆角矩形图标底衬，清理旧产品标识、兼容迁移代码与无用参考文件。

使用前安装 **x64 .NET 10 Desktop Runtime** 和 **Windows App SDK Runtime 2.5.1 或更新的 2.x 稳定版**，详见 [运行组件下载](https://github.com/YuzakiKokuban/LumaDesk/blob/main/docs/RUNTIMES.md)。程序始终以管理员权限运行；原厂 UWACPIDriver 需保留。

常用功能包括官方办公 / 均衡 / 狂暴档位、一键强冷、充电上限、单色键盘背光和 Windows 系统设置。MUX 保存路径已实现，本机重启后的物理切换尚未验证。测试记录见 [VALIDATION.md](https://github.com/YuzakiKokuban/LumaDesk/blob/main/docs/VALIDATION.md)。

通过 30 项 Rust 测试、9 项 EC / MUX 协议测试、WinUI Debug / Release 构建、包内容与图标检查。本机安装、启动、卸载和 OEM 接管恢复测试通过；CI 重复执行安装与卸载检查。
