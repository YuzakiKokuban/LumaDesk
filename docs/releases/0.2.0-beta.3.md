# 机耀处 · LumaDesk 0.2.0-beta.3

- 打开窗口时默认最大化；还原为普通窗口后，宽和高分别为所在显示器分辨率的一半，并居中。
- 屏幕亮度 OSD 接收 Windows 的实际亮度变化，显示百分比，覆盖 Fn+F11/F12 或系统调节；接收推送事件，不在后台轮询亮度。
- 安装器继续固定要求管理员权限、禁止切换为当前用户安装，并增加安装入口的管理员检查。
- 收起窗口时卸载页面与导航控件，回收可释放内存并释放空闲工作集；重新打开时恢复页面。没有定时内存清理任务。

本机 Release 隔离模拟后端验证：后台启动工作集约 34MiB，窗口收起后约 29MiB，多次 OSD 和开关操作后约 42MiB；最后一次采样私有提交约 132MiB。50MB 目标针对后台工作集，私有提交尚未达到该数值；不同驱动、真实硬件后端和操作次数可能影响结果。Windows 原生亮度事件订阅已在本机建立，亮度百分比提示及隐藏时暂停硬件读取通过集成检查。

提供 Windows x64 安装器、便携 ZIP 和 SHA256 文件。依赖仍为共享 .NET 10 / Windows App SDK Runtime，原厂 UWACPIDriver 需保留。
