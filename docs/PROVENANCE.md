# 来源与许可

中文名“机耀处”，英文名 LumaDesk，新仓库 [YuzakiKokuban/LumaDesk](https://github.com/YuzakiKokuban/LumaDesk)。内部工程、命名空间与数据目录使用 JiYaoChu。版本从 0.1.0 开始。

WinUI/Rust 源码来自本地独立重建工作及本轮实现，不是官方源码恢复。保留协议分析结果用于复核，不分发原版 EXE、官方驱动、DLL、受保护程序或反编译源码目录。

协议证据来自本机机械革命控制中心的 ECSpec、LightingModel.EC_SPEC、UEFI 元数据，官方 ACPIDriverDll/UWACPIDriver，以及 OpenRevo 0.8.5 的原生调用序列。官方多数业务方法仍被保护，无法声称完整复制全部分支。来源、常量、调用地址与验证边界见 [协议报告](../reverse/native/REPORT.md)。

旧 OpenRevo 图标、收款码、赞助页、旧截图与无用 UI 页面已移除。Logo 使用用户提供的 abstract-dark-geometry.svg 原文件，保存为 assets/LumaDesk.svg；保留透明背景、双弧路径与原始配色。scripts/generate-icons.ps1 只转换 PNG/ICO 格式，不重新设计图形。新仓库不导入旧仓库提交历史。

项目采用新仓库既有 MIT License；旧仓库相关材料所需版权声明保留在 [第三方说明](../THIRD_PARTY_NOTICES.md)。名称和来源说明不对开源履约争议作未经核实的结论。
