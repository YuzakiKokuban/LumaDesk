# 项目资料与许可

机耀处使用 C# / WinUI 3 前端和 Rust 硬件后端，源码与构建流程保存在本仓库。内部工程、命名空间与数据目录使用 JiYaoChu。

仓库保留协议分析结果与实机验证记录，不分发官方程序、驱动和 DLL。

协议资料包括本机机械革命控制中心的 ECSpec、LightingModel.EC_SPEC、UEFI 元数据、ACPIDriverDll 与 UWACPIDriver 分析，以及早期参考调用的交叉核对。当前保留官方接口证据、离线协议测试和本机验证记录，详见 [协议报告](../reverse/native/REPORT.md)。

`assets/LumaDesk.svg` 是用户提供的原始 Logo，保持原始字节、路径与配色。生成的 PNG 和 ICO 使用白色圆角矩形底衬。
