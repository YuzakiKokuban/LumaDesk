# 体积与运行开销


## 趋势绘制开销（2026-10-05）

Release、隔离模拟后端，在真实窗口内挂载三张宽 600 DIP 的图，各使用 600 个采样并包含隐藏断点与缺值，连续更新 30 次。计时覆盖三图的 Show 与 UpdateLayout；采样准备在计时外，不含硬件读取、整页 Reactor 更新或物理鼠标响应。完整数据见 [比较记录](../reverse/native/evidence/trend-refresh-comparison.json)。

| 三图一次更新 | 旧实现 | 当前实现 |
| --- | ---: | ---: |
| 中位耗时 | 7.06ms | 7.94ms |
| P95 | 17.34ms | 10.64ms |
| 最大耗时 | 22.28ms | 13.85ms |

本次测量的中位耗时没有改善；较慢更新的 P95 和最大值下降约 39% 和 38%，不能表述为所有刷新都更快。原始未挂载图表的计时没有完整覆盖绘制，已弃用。旧实现未通过控件保留断言，作为预期的回归复现；当前实现通过同一断言、原生几何断点和离屏恢复检查。

图表改为复用刻度、标签和两个 Path，批量解析曲线，减少逐点 WinRT 调用与临时装箱数组。使用 [WinUI 有效视口事件](https://learn.microsoft.com/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.frameworkelement.effectiveviewportchanged) 跳过离屏几何更新；保留同一套采样和缺值规则，没有降低采样频率。实际设备和较长运行的输入/滚动延迟仍需测量。

## beta.4 清理频率与重开响应

2026-10-03，Release、隔离模拟后端、200% 缩放，执行五个页面的设置和截图检查。连续 OSD 没有触发额外回收；三次重开到低优先级 UI 队列处理约 93、356、289ms，这不是完整硬件读取或首帧渲染耗时，也没有用它宣称相对旧版更快。

后台启动清理后工作集约 12.76MiB，私有提交 103.91MiB。连续页面操作后第一次收起采样工作集仍为 157.25MiB，清理冷却期内允许已访问内存驻留；持续空闲并完成延迟清理后工作集约 4MiB，随后约 6.07MiB，私有提交仍为 147.85MiB。工作集释放会让页再次访问时重新驻留，不能把这个低值当成总内存消耗。完整记录见 [Release 检查](../reverse/native/evidence/settings-release-validation.json)。

主窗口收起安排一次可取消的清理，至少延迟 2 秒，两次清理至少间隔 60 秒；OSD 消失不再强制 GC。没有周期清理任务。真实硬件、较长运行和其他负载仍需单独测量。

## beta.3 后台优化

2026-10-03，Release、隔离模拟后端：后台启动工作集 34.21MiB，第一次收起后 28.78MiB，多次 OSD 提示和 Win 锁切换后的空闲工作集 42.00MiB，私有提交 131.57MiB。空闲 3 秒的 CPU 时间增量为 0。记录见 [窗口与内存验证](../reverse/native/evidence/window-brightness-memory-validation.json)。

收起时卸载页面和导航控件，执行一次托管回收和空闲工作集释放；OSD 消失后也可释放空闲工作集。没有周期清理或后台遥测。工作集指当前驻留物理内存，私有提交仍由 WinUI、.NET 和原生组件保留，不能将二者都宣称为 50MB；真实硬件后端和更长运行的占用仍需验证。

2026-10-02，耀世 15 Air，Release x64。应用位于状态概览页，记录启动后 40 次约一秒间隔采样，取后 20 次平均值。

包大小为 GitHub Release 的 CI 干净构建产物，重新下载后完成校验。内存数据来自本机候选构建。新版共用系统 .NET 与 Windows App SDK 运行时，运行时的磁盘占用不包含在程序目录中；不同程序可以共用同一份组件。测量脚本为 scripts/measure-runtime.ps1。

机型与 BIOS 缓存 5 分钟，电池健康缓存 60 秒，WMI 时钟查询缓存 5 秒。温度、负载、风扇、电量及控制状态仍每秒刷新，操作后主动触发读回。前端缓存反射属性，合并快照通知，复用单个轮询循环；导航不缓存页面或累积顶层历史。

上述内存数据来自本机各一次运行，受后台负载、驱动和窗口状态影响。启动时间与 CPU 样本波动较大，未作为性能提升指标。
