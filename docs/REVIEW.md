# 项目审查

版本 0.1.2，2026-10-02。检查范围包括 Rust 硬件层、API/FFI、配置与后台轮询、WinUI 页面、OEM 服务管理、便携发布和 CI/CD。

| 问题 | 修复 |
| --- | --- |
| 键盘亮度误用 7AB，与实际 EC RGB 路径不符 | 改用 78C，清除 7C5 固件效果选择器，保留无关字段 |
| 自清零的命令位被当成持续接管状态 | 读回忽略提交位，使用持久亮度及关闭位判断状态 |
| 灯光写入后页面仍显示草稿 | 写入成功后重新读取硬件；保留颜色量化对应的已选预设 |
| 颜色按钮宽度过大、最后一个按钮孤立 | 统一紧凑尺寸、左对齐、按可用宽度换行 |
| 控件挂载事件误触发设置 | ToggleSwitch 和 ComboBox 过滤初始值、相同值与无效索引 |
| 满电不充电被显示成使用电池 | 分开记录 AC 供电与充电状态 |
| 充电上限部分写入失败留下混合设置 | 备份相关寄存器，失败时恢复 |
| 自启动关闭时不存在任务被误报失败 | 成功分支显式返回成功；注册、查询、调度启动与恢复通过实机测试 |
| 后台初始化或非 CoreException 错误使轮询永久退出 | 显示错误并在后续轮询重试 |
| 模拟后端启动仍可能接管本机 OEM 服务 | 模拟模式跳过自动接管 |
| Windows 图标资源编译失败被忽略 | 构建失败退出；包验证对比全部嵌入图标 |
| 发布脚本版本比较错误 | 从 XML 单节点读取版本并与 Rust 版本比较 |
| Debug 专属依赖影响 Release 锁定还原 | 分开锁定 Debug/Release 依赖，CI 分别还原 |

CI 检查格式、静态分析、测试、WinUI 编译和最终包内容。标签发布依赖检查成功，标签版本必须与源码一致。

后续仍需处理的项目：动态 RGB、自定义风扇、GPU 调校及其他 OEM 开关；MUX 重启后显示路由；实际充电截止与键盘观察；全页面窄窗口视觉复核。具体测试证据见 [验证记录](VALIDATION.md)。
