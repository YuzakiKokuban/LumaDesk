# 功能矩阵

目标机型：耀世 15 Air / EC 项目 0x1A。Windows 电源模式与机身性能档位分别设置。

| 功能 | 实现 | 本机验证 |
| --- | --- | --- |
| OEM 三档 | 751 / 7AB / 767，读取固件默认 PL | 三档切换、回读、恢复通过 |
| Windows 电源模式 | AC/DC UserConfiguredPowerMode API | 三种模式设置与回读通过 |
| 键盘背光 | 78C 亮度，769–76B RGB，7C5 效果选择；六位十六进制自定义颜色 | 关闭、四档亮度、八种颜色读回通过；自定义颜色的实际灯光观察待确认 |
| 强冷与双风扇转速 | 751 bit 6，464–465 / 46C–46B | 实测强冷后双风扇转速明显上升 |
| 充电上限 | 770 / 7B9 / 7D0 / 7A6 | 60%、80%、100% 设置与回读通过；充电截止待观察 |
| Win 键锁定 | Windows 低级键盘钩子，左右 Win 键 | 按键投递测试通过：锁定拦截、解锁恢复、其他键不受影响 |
| Fn+F1 / Fn+F3 | ACPI 推送事件，接管后响应 | 本机记录到 F1=CC、F3=40/A5；呼出界面与锁定状态共用同一入口 |
| OSD | 原生置顶、不抢焦点、点击穿透、定时隐藏；新配置默认 60%，可自定义 20%–100% 不透明度 | Fn 功能提示、锁定键、音量/麦克风和供电变化；固件事件与系统事件覆盖范围见下表 |
| 后台与托盘 | 关闭/最小化收起，双击打开；右键提供性能三档、强冷与退出 | 隐藏时暂停完整遥测；后台模式键读取为独立选项，默认关闭 |
| 显卡 MUX | UEFI 模式字段 62 | 当前模式读取、编码与保留缓冲区测试通过；未切换重启 |
| 遥测 | Windows / ACPI / WMI / NVML | CPU、GPU、风扇、电池读取；CPU 功耗暂无读数 |
| OEM 接管与恢复 | GCUBridge 与所属启动任务 | 服务停止、恢复原启动状态、重新接管通过 |
| 管理员自启动 | 当前用户登录任务，Highest 权限，后台启动；升级迁移既有本程序任务 | 任务注册验证见验证记录；迁移采用隔离任务替身检查 |
| 显示设置 | 选择显示器与支持的刷新率；内置屏幕亮度，写入后读回 | 隔离模拟验证；外接显示器与实际亮度效果待实机确认 |
| 趋势图 | 最近五分钟的温度、负载、风扇转速；可清空历史 | 复用可见窗口遥测；缺失数据与隐藏间隔断开，不后台采样 |
| 设置恢复与迁移 | ZIP 预览、兼容性检查、自动回退备份；支持旧版备份 | 默认恢复应用偏好；硬件恢复需要显式选择，逐项报告结果 |

## Fn 与系统提示

本机键盘布局如下。Fn+F1 与 Fn+F3 由机耀处在接管后处理；其余行描述现有键盘功能对应的 OSD，依赖固件或 Windows 通知。仅收到无状态事件时显示“设置已切换”，不推测开关值。

| 按键 / 事件 | 提示内容 | 来源 |
| --- | --- | --- |
| Fn+Esc | Fn 锁 | 固件 FnChange |
| Fn+F1 | 呼出机耀处 | 本机已采集 CC |
| Fn+F2 | 麦克风静音 | 固件事件；Windows 默认通信麦克风静音通知 |
| Fn+F3 | Win 键锁 | 本机已采集 40 / A5，软件锁状态 |
| Fn+F4 | 飞行模式 | 已接入固件 A4 及项目 0x1A 的 Fn/F4 输入处理、Windows 全局切换与读回；本机物理按键尚未通过验证 |
| F12 右侧独立模式键 | 性能档位 | 读取 EC 实际档位；兼容物理键 20/30 编码，主窗口及托盘均可显示 OSD |
| Fn+F5 | 触摸板开关 | 固件 TPON / TPOFF |
| Fn+F6 / Fn+F7 | 键盘背光调低 / 调高 | 固件亮度档位或变更通知 |
| Fn+F8 | 静音 | Windows 音频通知；固件 MUTE |
| Fn+F9 / Fn+F10 | 音量减小 / 增大 | Windows 实际音量通知；固件音量事件 |
| Fn+F11 / Fn+F12 | 屏幕亮度百分比 | Windows WmiMonitorBrightnessEvent 实际值；固件事件提示方向作为补充 |
| Caps Lock / Num Lock / Scroll Lock | 已开启 / 已关闭 | Windows 键盘事件 |
| 连接或断开电源 | 电源 / 电池 / 备用电源 | Windows 电源来源通知 |

普通 F1–F12 不被改绑。本机新增 Fn+Esc、Fn+F4 及独立模式键采集；Windows 飞行模式接口已完成切换与恢复。单独采集 Fn+F4 时只见 Fn 标记，未收到 F4/F24 或 A4，物理快捷键仍未完成适配；详见 [输入证据](../reverse/native/RADIO.md)。

动态 RGB、单键/分区背光、自定义风扇曲线、GPU 功耗调校、系统页面的 Fn 锁设置、关机 USB、断电恢复和 BIOS 高级菜单尚未接入。系统页面展示适配说明，已实现的开关正常开放。

详细记录见 [验证文档](VALIDATION.md)，地址和调用证据见 [协议报告](../reverse/native/REPORT.md)。

自动性能档位默认关闭，可在电源页设置连接电源与电池/备用电源规则，通过电源推送事件切换；隔离模拟往返通过，实际插拔和睡眠恢复仍需确认。系统页支持诊断 ZIP 与配置备份 ZIP 导出，并可手动请求通知重连。诊断含缓存读数及时间戳，备份包含配置、机型和自定义文件；导出不会应用硬件设置。
