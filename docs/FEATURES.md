# 功能矩阵

目标机型：耀世 15 Air / EC 0x1A。状态区分实现、寄存器/API验证与实际设备行为。

| 功能 | 实现 | 验证边界 |
| --- | --- | --- |
| OEM 档位 | 751 / 7AB / 767，固件 PL 默认值 | 三档回读通过；未测整机功耗和完整官方业务分支 |
| Windows 模式 | AC/DC UserConfiguredPowerMode API | 三种模式回读通过，与 OEM 档位独立 |
| RGB | 766 能力位、769–76B 色彩、7AB 亮度、78C 控制权 | RGB/亮度回读通过；动态效果尚未接入，未观察实际灯色 |
| 强冷 / 转速 | 751 bit 6 / 464–465、46C–46B | 强冷位往返验证；长时间响应待测 |
| 充电上限 | 770 / 7B9 / 7D0 / 7A6 | 已实现；实际充电截止待测 |
| Win 键锁定 | 768 bit 0 | 已实现；按键行为待测 |
| MUX | UEFI 模式字节 62、Door、长度保留 | 读取成功；保存代码和离线测试，未切换或重启 |
| 遥测 | Windows / ACPI / WMI / NVML | 实机读取；CPU 功耗暂无，ACPI 温度非核心温度 |
| OEM 接管 | 仅 GCUBridge 安装根目录与所属计划任务 | 停止/禁用、恢复原 Auto/Stopped、重新接管均通过 |
| 自启动 | 当前用户登录任务、Highest 权限 | 已实现；重新登录待测 |
| 自定义风扇、GPU 功耗 | 协议不完整 | 不开放 UI 操作 |
| Fn 锁、关机 USB、断电恢复、BIOS 高级菜单 | 未接入 | 系统页列出状态，不提供灰色假开关 |
| 独立 OSD、水冷、动态 RGB、单键和分区 | 未完成 | 不显示可操作的无效设置 |

自定义机型 JSON 只保存预设，不会解锁硬件功能。配置保存、事件排队和日志写入也不是设备功能实现。
