# EC 项目 0x19：翼龙 15 Pro（GM5HG0A）

更新：2026-10-11。AMD R7 8845H + RTX 4060，BIOS N.1.09MRO19，官方控制中心 ControlCenter3 5.17.51.34。`UWACPIDriver.sys` 的 SHA256 与 [协议报告](REPORT.md) 中的样本相同，EC 传输层直接复用。

地址结论来自只读对比：在官方控制中心里切换一项设置，前后各读取 EC 0x400–0x4FF 与 0x700–0x7FF，取两次读数一致的字节作差。写入只验证了下文“写入验证”中的两个字段。

## 与 0x1A 相同

| 用途 | 地址 | 本机观察 |
| --- | --- | --- |
| 项目代号 | 740 | 19 |
| 档位字段 | 751 | 办公 A0、均衡 00、狂暴 10 |
| CPU 风扇 RPM | 464 高 / 465 低 | 强冷时 09xx → 17xx |
| EC RGB 支持位 | 766 bit 2 | 已置位 |
| RGB 通道 | 769 / 76A / 76B | 0–50；官方把零通道写为 1 |
| 键盘亮度与关闭位 | 78C | 四档 20/40/60/80，bit 1 关闭 |
| 风扇渐变 | 787 | 启用 300 ms 时为 83，停用为 00 |
| 默认 PL | 730–732 / 734–736 | 65/65/100、35/35/70 |
| 自定义档位覆盖 | 726 bit 7 | 自定义模式下置位，751 字段保持 00 |

## 与 0x1A 不同

| 用途 | 0x1A | 0x19 |
| --- | --- | --- |
| GPU 风扇 RPM | 46C 高 / 46B 低 | 46C 高 / 46D 低 |
| 46A / 46B | — | 当前生效 PL1 / PL2：办公 35、均衡 65、狂暴 90 |
| 46F | — | 当前 PL4：办公 70，其余 100 |
| 强冷 | 751 bit 6 | 768 bit 2，仅自定义模式提供；同时 75B/75C 变为 C8 |
| 充电上限 | 7B9 / 7D0 | 固件不提供，两处恒为 0 |
| 切档时的 783–785、7AB | 由软件写入 | 官方三档下恒为 0，不写入 |

狂暴档还会改变 743（01→07）、745（00→FF）、746（00→19，与 Dynamic Boost 25 W 一致）、7C4（20→38）、7D4/7D5。写入验证表明这些字节不由 EC 联动。75B/75C 随档位取 5A/46/3C，强冷时 C8，推测为风扇占空比，未验证。

43E/44F 读数在 50–61 之间缓慢变化，与 CPU/GPU 温度相符，没有独立温度来源交叉确认。

## 写入验证

[write_test.py](evidence/project-19/write_test.py) 在官方均衡档下执行，结果见 [write-test.json](evidence/project-19/write-test.json)。

| 写入 | 结果 |
| --- | --- |
| 751 档位字段 → 10 | 46A/46B 由 65 变为 90，46F 保持 100 |
| 751 档位字段 → A0 | 46A/46B 变为 35，46F 变为 70 |
| 751 档位字段 → 00 | 46A/46B 回到 65，46F 回到 100 |
| 768 bit 2 置位 | 写后读回成功，6 秒后已被清零，风扇转速不变 |

只写 751 档位字段即可让固件切换 CPU 功耗限制。743/745/746/7C4/7D4/7D5 没有随之变化，说明官方狂暴档的这组 GPU 字节由官方软件另行写入；机耀处尚未复现，因此 0x19 的狂暴档不包含 Dynamic Boost 提升。

强冷位在内置档位下不生效，与官方界面只在自定义模式提供强冷一致。

## 显卡模式变量

管理员读取：仅有 `UniWillVariable`（180 字节，APVersion 23，模式字节 01，按 AMD 编码为独显）。`OemMagicVariable` 与 `OemDgpuPresent` 均不存在（错误 203）。后端以 `OemDgpuPresent` 判定是否开放切换，所以本机显示为不支持；没有执行模式写入或重启验证。

## 后端范围

- 读取：档位、风扇转速、强冷状态、EC 温度。
- 切档：只写 751 档位字段；自定义档位（726 bit 7）生效时拒绝，退出路径未验证。
- 不开放：强冷写入、充电上限、显卡模式切换。
- 键盘 RGB 由 766 支持位控制，没有项目判断；本机寄存器含义一致。
