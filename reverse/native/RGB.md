# EC RGB 协议

适配本机耀世 15 Air / EC 项目 0x1A。地址定义来自官方 `LightingModel.EC_SPEC`，控制字节与提交顺序由原生调用及本机读写验证交叉确认。

| 地址 | 字段 | 用途 |
| --- | --- | --- |
| 766 | bit 2，掩码 04 | EC RGB 支持位 |
| 769 / 76A / 76B | 0–50 | 红、绿、蓝通道 |
| 78C | bits 5–7 | 四档亮度，持久读回值 20 / 40 / 60 / 80 |
| 78C | bit 1 | 显式关闭背光 |
| 78C | bit 4 | 命令提交位，固件处理后自动清零 |
| 7C5 | bits 0–2 | 固件效果选择器，单色控制清零；保留其余位 |
| 767 | bit 5 / bit 7 | 提交 RGB 更新 / 欢迎灯效 |

亮度写入值依次为 `12 / 30 / 50 / 70 / 90`，同时保留 78C 原有的 `0D` 掩码位。读回验证忽略自清零的 bit 4；零亮度且未置关闭位表示固件默认背光。不能把 bit 4 当作持续的接管状态。

颜色按 `channel × 50 / 255` 向下取整，非零通道至少为 1。先写控制字节、清除效果选择器，再写 RGB，最后清除欢迎位并触发 767 bit 5。失败时恢复已修改字节并重新提交。

此前 7AB 亮度判断来自另一条键盘路径；EC RGB 支持位存在时该路径不适用于本机。键盘控制现在不写 7AB，因此不会与机身档位字段冲突。

[亮度分支](evidence/key-disassembly/rgb-intensity-140364920.asm) 与 [颜色分支](evidence/key-disassembly/rgb-color-14029c940.asm) 保留相关调用片段。[实机报告](evidence/control-validation.json) 包含关闭、四档亮度、八种颜色，以及每次灯光修改后的三档性能切换检查。寄存器与 API 读回通过，实际灯光观察另行确认。

当前界面提供单色常亮，动态效果、单键与分区未接入。
